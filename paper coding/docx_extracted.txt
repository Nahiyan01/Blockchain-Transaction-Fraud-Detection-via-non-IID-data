System Methodology & Pipeline  Architecture 762000 104167 The authors introduce a unified 5-stage FL-XAI pipeline designed to achieve privacy, scalability, and transparency without adding network or computational overhead during model training: Stage   1:   Preprocessing   &  Imputation Cleans   raw   logs,   imputes   missing   values   (continuous      mean,   categorical      mode),   and   strips   zero-variance  columns. Stage 2: Client  Partitioning Distributes   data   across   20   client   nodes   under   IID   (balanced)   and   Non-IID   Dirichlet   (    =   1.0,   0.1,   0.01)  settings. Stage 3: Local  Training Trains   local   models   (2-Layer   Neural   Network   vs.   Tabular   Transformer)   using   SGD,   Adam,   or   AdaGrad   optimizers. Stage 4:  FedAvg   Aggregation Central   server   aggregates   local   model   weights   via   weighted   averaging   across   communication   rounds (200-500 CRs). Stage 5: Post-Hoc  XAI Executes SHAP (via  Shapash ) and LIME centrally post-aggregation, adding  zero communication  overhead to  clients.
